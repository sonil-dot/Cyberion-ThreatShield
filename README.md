# Cyberion ThreatShield
Detection Engineering & Threat Hunting engagement (CDL-DET-V2).

## Folders
- sigma_rules/ - Sigma detection rules
- datasets/ - EVTX telemetry used for testing
- data_dictionary/ - log field notes, rule test reports, evidence records
- coverage_matrix/ - MITRE ATT&CK coverage
- threat_hunts/ - hunt reports
- incident_reports/ - incident case reports
- playbooks/ - IR playbooks
- ioc_research/ - IOC notes
- final_report/ - final report and executive summary
